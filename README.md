# Sarah Records · Catálogo SARAH 1–100

Catálogo visual de [Sarah Records](http://sarahrecords.org.uk/) (Bristol, 1987–1995): los 100 lanzamientos de la serie principal, con portadas, fichas, tracklists y enlaces para escuchar.

## Ver online

Si GitHub Pages está activo: `https://raul-marin.github.io/sarah-records-catalog/`

## Local

```bash
python3 -m http.server 8765
```

Abre http://localhost:8765
